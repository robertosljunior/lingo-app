# L2 vertical semantic-network pilot

Issue: #91

This slice is deliberately offline/library-only. It proves the semantic-network contract before any broad noun/verb expansion or learner-facing integration.

## Frozen boundaries

- lexical verb data owns `sense` and `argument_frame`, not pedagogical `construction`;
- no generic lexical `pattern_en`;
- typed `proposition_plan` is the interface to later construction composition;
- incompatible fixed/requested features fail with `PROPOSITION_FEATURE_CONFLICT`;
- lexical data is semantically authoritative and pedagogically neutral;
- cross-lingual error patterns are negative contracts, not automatic distractors;
- semantic entities carry countability where relevant;
- existing places are reused cross-registry instead of duplicated;
- no imports from lesson engine, builtin pedagogy catalogue, recognition option building, or V2.24 licensed-realization materialization.

## Pilot scope

The pilot contains 8 verb lexemes and 12 non-place semantic entities. The committed tests cover positive and negative compositions, cross-registry place use, countability rejection, proposition feature conflicts, deterministic signatures, learner-evidence target isolation, and static runtime isolation.

The pilot is an architecture test only. Its candidate/combination counts are not learning claims and do not define the future active working-set size.
